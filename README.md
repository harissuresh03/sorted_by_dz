# Sorted by DZ

Sorted by DZ is a Malaysia-based personal service-connection website. Customers can describe what they need and request help finding a suitable service provider, without having to search through providers themselves.

## Business Overview

The business connects customer requests with relevant providers across three service areas:

- **Nightlife:** club table reservations, guest-list arrangements, promoters, ambassadors, and nightlife entertainers.
- **Marketing and Digital:** branding, social-media support, photography, videography, event services, entertainment, catering, wedding services, and website development.
- **Household & Living Needs:** moving services, lorry rental, home maintenance, interior design, and vegetables supply.

Provider partners can introduce their services through the partnership form. Sorted by DZ reviews the information and may contact providers when a future request matches their offering. A partnership or booking is not guaranteed.

## Website Features

- Customer enquiry form for requesting a service.
- WhatsApp contact option for direct enquiries.
- Service explorer with category and service details.
- Partnership form for service providers.
- Multiple supporting-file uploads on the partnership form.
- File deletion before submission and a 10 MB per-file limit.
- Email delivery through Nodemailer and SMTP.
- Responsive pages for home, services, contact, partnerships, privacy, and terms.

## Getting Started

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in a browser.


## Useful Commands

```bash
npm run typecheck  # TypeScript validation
npm run build      # Production build
npm run start      # Start the production build
```
